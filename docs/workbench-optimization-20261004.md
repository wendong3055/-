# 工作台优化记录 · 2026-10-04

目标：第一次使用的人能够找到下一步，并完成第一张效果图。

## 使用流程

- 默认使用「快速上手」：选搭配 → 写要求 → 核对并生图。
- 「完整设置」保留所有原有选项；切换模式和步骤不重置当前选择。仅保存界面模式偏好，不自动保存未提交的制作草稿。
- 桌面端选项区单独滚动，步骤与下一步按钮保持可见；窄屏使用上下布局。
- 快速上手先显示四款框架，所选框架始终在首位；可进入框架库选择其他款式。
- 模型参数、原图辅助检查及要求整理默认收起。三种用途改用日常语言说明。

## 生图前的准备

- 本轮统一前端可生成状态与操作提示：任务读取中、进行中、待核对、未连接、缺少原图、缺少框架、已确认产品搭配不符。
- 有可处理的缺项时，提供对应页面入口。
- 初次载入优先选择带有已核对原图的图案；用户手动选择后不覆盖其选择。
- 快速上手中的预览生图入口先进入核对步骤；模型、参数、搭配及文字沿用当前值。切换步骤和界面不会调用生图。
- 核对区说明生成数量与服务商计费，沿用原有单张提交、重复提交锁、样稿验收和批量确认机制。

## 导航与连接

- 首页、产品与记录使用更直白的名称，四个素材库收纳在「素材管理」。
- 连接页明确展示保存密钥和启用密钥两步，消除原来的多层折叠。
- 已有连接的人可直接返回制作；保存新密钥后提示继续启用。
- 预览在无结果时标明「参考图片」，避免与已生成效果混淆。

本轮未修改数据库结构、密钥保存协议、收费接口或素材文件，也未执行真实收费生图。

## 检查结果

- TypeScript 类型与 Git 差异格式检查通过。
- 离线检查覆盖各类不可生成状态、处理入口、三步导航、默认收起内容、核对摘要、参考图区分、连接设置及优化记录的渲染。
- 所有检查禁止网络请求，没有提交真实生图任务。
- 当前环境未提供所需的浏览器测试能力，因此本轮未进行浏览器交互和视觉实测。
