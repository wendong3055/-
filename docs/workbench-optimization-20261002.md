# 工作台优化（2026-10-02）

基于 v95 / 4cb3ef03f99630296e76cbfa62c8151eb2986d3a 更新原工作台。

- 生成效果默认仍为单张大图；点击“对比两版”可选另一张已完成结果，两边共享倍率、完整/填满模式及全屏视图。
- 从已保存 recipe 显示每轮设置差异；缺少设置的旧记录不推测差异，设置相同标为重新试做。
- 收藏保存在 generation_tasks.favorite，按登录账号校验；收藏可超出最近100条记录读取，整个列表仍有500条边界。
- 批量入口先只做一张样稿。尺寸页先做统一背景样稿；全套先做一张主图。生成后停止，用户验收并再次点击、确认准确余图数量后才继续。
- 已生成历史样稿可验收，不为新流程重新收费。余图沿用样稿模型、画质及摆件配置；成功样稿阶段锁定批量设置，新一套可重新设置。
- 主图样稿作为后续主图/全套的产品视觉参考；尺寸图保留自己的原框架和统一背景；单页详情试样核对出图设置，仍使用原确认产品作为参考。
- 前后端都核对样稿当前 generationId、成功结果与验收状态。单页必须同计划，全套使用当前主图计划首样稿，规则和备注一致。实际收费提交前再次核验验收。
- 保留串行、任务锁、未知状态暂停、原图及旧结果；无自动重试。页面仍需保持打开才能连续提交。
- 新增迁移仅添加 favorite 常量默认列；不改已有数据或密钥。

验证：TypeScript；预览组件与比较/收藏操作；真实 SQLite 全部迁移、收藏归属/跨站保护；样稿和余图实际按钮 handler 的 mock 流程；真实生成路由的 mock gate；单项调整/重做；原图库267哈希及结构/场景/尺寸回归。没有真实 RunningHub 生图或费用。
