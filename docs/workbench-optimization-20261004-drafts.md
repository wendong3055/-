# 工作台优化记录 · 2026-10-04 第二轮

## 继续编辑

- 当前账号保留一份「制作一张图」的编辑草稿，保存搭配 ID、制作要求、模型参数和所在步骤。
- 正常编辑停顿后自动保存；切换页面或隐藏标签页时尽量完成尚未保存的写入。以页面显示「编辑已保存到账号」为成功标志，离线或网络失败时会明确提示。
- 再次打开可继续上次编辑，也可用本页搭配开始下一稿。恢复前检查素材与模型，缺项时允许只恢复文字。
- 草稿不包含密钥、图片文件、收费确认、任务 ID 或自动重试状态，恢复不会提交生图。
- 账号隔离，读写都由服务端验证身份。版本号用于避免多标签页或多设备的编辑互相覆盖；冲突需明确选择保留的内容。
- 已确认产品的单项制作不会写入这份普通编辑草稿。

## 任务处理

- 预览区区分进行中、失败和状态不明的任务。
- 失败任务可带回设置修改，仍需核对并手动点击生成。
- 状态不明时只引导查看记录及核对，保留原有解除锁定确认。
- 带回历史设置前先核对模型可用性，避免只恢复了一半设置。

## 数据变更

新增 `studio_drafts` 表，按账号存一份草稿，并记录版本号、更新时间。迁移只新增表，不更改既有任务、作品、产品或密钥数据。

## 验证

- 类型检查、差异格式检查通过。
- `node scripts/check-studio-draft.mjs` 使用真实接口处理函数和 SQL，在内存数据库验证身份隔离、跨站请求拒绝、内容校验、大小限制和版本冲突。
- 检查新增迁移保留原表数据，并验证素材缺失提示、任务状态和页面渲染。
